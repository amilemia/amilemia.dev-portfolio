# Web Performance Checklist

Measure a real page, identify the likely bottleneck and leave with a short list of fixes you can verify.

## Inside the four-page PDF

1. **Measure before changing** - Record the page, device and starting point.
2. **Run the performance checks** - Review loading, interaction and stability.
3. **Choose fixes from evidence** - Match symptoms to practical investigations.
4. **Build a verification plan** - Assign the next fix and compare the result.

Includes interactive checkboxes and text fields. You can also print a copy.

The workbook separates lab investigations from real-user field data and links to official web.dev guidance. A Lighthouse score alone is not a Core Web Vitals pass.
