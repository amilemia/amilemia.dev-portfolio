# Projet Hello World

Ce projet d'exemple montre comment utiliser Contentlayer2 avec Next.js 15. Il met en avant plusieurs fonctionnalités :

- Support MDX avec frontmatter
- Contenu typé de manière sûre
- Génération automatique des types

## Fonctionnalités

- **Stack moderne** : Next.js 15, TypeScript et Tailwind CSS
- **SEO friendly** : génération automatique du sitemap et du flux RSS
- **Rapide** : optimisé pour la performance avec chargement différé et optimisation des images

## Prise en main

1. Clonez le dépôt
2. Installez les dépendances avec `npm install`
3. Lancez le serveur de développement avec `npm run dev`

## Stack technique

- Next.js 15
- TypeScript
- Tailwind CSS
- Contentlayer2
- MDX
